ÁRVORE BRÔNQUICA — JOGO PWA

Arquivos prontos para GitHub Pages.

COMO PUBLICAR
1. Crie um repositório no GitHub.
2. Envie TODOS os arquivos desta pasta para a raiz do repositório.
3. Em Settings > Pages, publique a branch main pela pasta /root.
4. Aguarde o GitHub gerar o endereço.

COMO JOGAR
- Digite o nome do jogador.
- Toque em um nome anatômico na lista.
- Depois toque na letra ou número correspondente diretamente sobre o desenho.
- Acerto: nome e alvo ficam com a mesma cor e brilham.
- Erro: o alvo pisca em vermelho; o erro e a tentativa são registrados.
- O tempo corre durante toda a tentativa.
- Ao completar as 26 estruturas, a sessão é salva como concluída.
- Se a página for fechada ou uma nova tentativa for iniciada antes do fim, a sessão anterior fica registrada como interrompida.
- O histórico fica salvo no próprio aparelho via localStorage.
